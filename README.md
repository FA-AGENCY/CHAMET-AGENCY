# RAYHAN AGENCY — Redesigned Website

Dark navy + electric blue/purple/pink + gold theme matching the provided design mockup.

## Pages

- `index.html` → redirects to Login
- `pages/login.html` — Login page
- `pages/signup.html` — Registration
- `pages/forgot-password.html` — Password reset
- `pages/dashboard.html` — Main dashboard with service cards
- `pages/diamond-topup.html` — Diamond packages + payment flow
- `pages/host-register.html` — Multi-step Host registration
- `pages/agency-info.html` — Multi-step Agency registration
- `pages/profile.html` — Profile & settings

## How to run

1. Open `index.html` or `pages/login.html` in a browser (frontend is static).
2. For backend (optional):
   ```bash
   npm install
   node server.js
   ```

## Design system

- Background: `#050816`
- Accent gradient: Blue → Purple → Pink
- Gold accents for logos & Agency CTA
- Cards with soft glow borders
- Mobile responsive
